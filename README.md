# 💛 Sally | Experimental Large Language Model

> Every intelligent conversation begins with a single prompt.

Sally is an experimental Large Language Model (LLM) project focused on natural conversations, emotional intelligence, reasoning, and personality-driven AI interactions.

Designed as an ongoing research project, Sally explores how conversational AI can become more engaging, context-aware, and human-like while remaining simple and accessible through a browser interface.

---

# 📖 About

Sally is the primary Large Language Model project developed by the author to experiment with modern conversational AI.

Unlike traditional chatbots that rely on predefined responses, Sally generates dynamic conversations using LLM technology, allowing users to have more natural, context-aware, and meaningful interactions.

The project is continuously improved through prompt engineering, interface refinements, and AI experimentation.

# ⚙️ Working Principle

1. User enters a prompt.
2. The request is sent to the language model.
3. Sally analyzes the conversation context.
4. The AI generates a contextual response.
5. The response is displayed in the chat interface.
